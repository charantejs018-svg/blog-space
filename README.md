# Editorial Tale Spin

Create a modern, responsive full-stack blogging platform frontend called BlogSpace.

Use React, TypeScript, Tailwind CSS, and reusable components.

For this first stage, focus on the frontend only. Do not connect Supabase yet.

Create the following pages:

Home page with a hero section, featured blog, latest posts, and category filters.

Blog details page with article content and comments.

Login page.

Sign-up page.

Create and edit post page.

User dashboard showing published posts and drafts.

User profile page.

Design:

Professional editorial style.

Off-white background, dark text, and violet accent color.

Responsive layout for desktop and mobile.

Beautiful blog cards with cover images.

Sticky navbar with BlogSpace logo, Home, Explore, Login, Sign Up, and Write a Story.

Consistent typography, spacing, and reusable components.

Use realistic mock blog posts and author profiles.

Add frontend interactions for navigation, search, category filters, liking posts, and adding comments using local state.

Use React Router for navigation where appropriate.

Keep the code organized and easy to understand. Use TypeScript types for posts, comments, and user profiles.

Do not pretend that mock authentication or local-state data is connected to a real backend.

Build the homepage and shared navigation first, then implement the other pages. Make sure the project runs correctly.
